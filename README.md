# Transcriber

> Легковесная и быстрая утилита для мгновенной транскрипции аудио с микрофона в буфер обмена или активное окно с помощью OpenRouter API (Gemini Flash).

Приложение работает абсолютно незаметно в системном трее Windows/macOS, не имеет постоянного главного окна (для максимальной экономии оперативной памяти) и мгновенно активируется по одному глобальному сочетанию клавиш.

---

## ⚡ Быстрый старт

### 1. Установка зависимостей
Для работы приложения требуются библиотеки захвата звука и глобального перехвата клавиш.
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python src/main.py
```

---

## ✨ Ключевые особенности

- **Работа в системном трее** — приложение запускается полностью скрытым, не отвлекая от работы и не захламляя панель задач.
- **Оптимальное потребление памяти** — потребление RAM составляет всего ~40–60 МБ благодаря отложенной (lazy) инициализации окна настроек. При закрытии настроек окно полностью удаляется из памяти.
- **Глобальный хоткей** — удобная активация записи микрофона по одной кнопке (например, `Ctrl+Shift+Space` на Windows) через библиотеку `pynput`.
- **Интеграция с OpenRouter** — сверхбыстрое распознавание речи с использованием модели `google/gemini-flash-1.5` через `requests`.
- **Вставка на лету** — распознанный текст автоматически копируется в буфер обмена или эмулирует ввод клавиатуры прямо в активном текстовом поле.
