# Конфигурация приложения

В этом документе подробно описаны все доступные настройки утилиты **Transcriber**, способы хранения конфигурации и управление горячими клавишами.

---

## ⚙️ Файл конфигурации

Приложение сохраняет настройки локально в файле `config.json` в домашней директории пользователя или в корневой папке проекта.

Пример структуры `config.json`:
```json
{
  "api_key": "your-openrouter-api-key",
  "model": "google/gemini-flash-1.5",
  "hotkey": "<ctrl>+<shift>+space",
  "system_prompt": "You are a precise speech-to-text transcriber. Transcribe the audio exactly as spoken without adding any introductory or concluding remarks.",
  "audio_duration_limit": 30,
  "insert_mode": "clipboard"
}
```

---

## 🔑 Настройка OpenRouter API

Для выполнения транскрипции приложение отправляет аудио на OpenRouter. 
1. Перейдите на сайт [OpenRouter](https://openrouter.ai/) и зарегистрируйте аккаунт.
2. Создайте новый API-ключ в разделе **Keys**.
3. Скопируйте ключ и вставьте его в поле **OpenRouter API Key** в настройках приложения.

---

## ⌨️ Настройка глобального хоткея

Глобальный хоткей отслеживается с помощью библиотеки `pynput` даже тогда, когда приложение свернуто.
- Допустимые клавиши модификаторы: `<ctrl>`, `<shift>`, `<alt>`, `<cmd>`.
- Стандартные комбинации:
  - **Windows:** `<ctrl>+<shift>+space`
  - **macOS:** `<cmd>+<shift>+space`

> [!WARNING]
> Не назначайте хоткеи, которые уже используются вашей операционной системой для системных действий (например, `cmd+space` на macOS для Spotlight).

---

## 🎙️ Режимы вывода текста (Insert Mode)

Вы можете выбрать один из двух режимов работы после завершения транскрипции:
1. **Clipboard (Буфер обмена):** Текст просто копируется в буфер обмена. Вы можете вставить его в любое место вручную с помощью `Ctrl+V` / `Cmd+V`.
2. **Typewriter (Печатная машинка):** Приложение автоматически эмулирует нажатие клавиш клавиатуры и печатает распознанный текст непосредственно в активное текстовое поле сразу после завершения распознавания.
