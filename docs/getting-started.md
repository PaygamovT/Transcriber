# Начало работы

В этом руководстве описаны системные требования, шаги по подготовке окружения и инструкции по первому запуску утилиты **Transcriber**.

---

## 📋 Системные требования

- **Операционная система:** Windows 10/11 или macOS 11+.
- **Интерпретатор Python:** Версия 3.10 или новее.
- **Аудиоустройства:** Рабочий микрофон (встроенный или внешний).

---

## 🛠️ Подготовка окружения

Приложение использует библиотеки `sounddevice` и `pynput` для захвата звука и клавиатурных событий. Для работы `sounddevice` на некоторых системах могут потребоваться дополнительные системные библиотеки.

### Windows
На Windows всё необходимое ПО устанавливается автоматически при установке Python-пакетов из `requirements.txt`.
Установите пакеты через pip:
```bash
pip install -r requirements.txt
```

### macOS
На macOS для работы `sounddevice` требуется библиотека `portaudio`. Установите её через Homebrew перед запуском:
```bash
brew install portaudio
pip install -r requirements.txt
```

## 🚀 Первый запуск

1. Склонируйте репозиторий на локальную машину:
   ```bash
   git clone https://github.com/PaygamovT/Transcriber.git
   cd Transcriber
   ```
2. Запустите приложение:
   ```bash
   python src/main.py
   ```
3. После запуска в системном трее (рядом с часами на Windows или в верхнем меню на macOS) появится иконка приложения.
4. Нажмите правой кнопкой мыши по иконке трея и выберите **"Settings"** (Настройки).
5. Введите ваш **OpenRouter API Key** и нажмите **Save**.
6. Закройте окно настроек — оно будет выгружено из оперативной памяти для экономии ресурсов.

---

## 🎯 Проверка работоспособности

1. Нажмите глобальное сочетание клавиш (по умолчанию `Ctrl+Shift+Space` на Windows или `Cmd+Shift+Space` на macOS).
2. Произнесите короткую фразу в микрофон.
3. Отпустите клавиши (или нажмите сочетание повторно в зависимости от режима записи).
4. Текст автоматически скопируется в буфер обмена, а на экране появится всплывающее уведомление трея о завершении транскрипции.
